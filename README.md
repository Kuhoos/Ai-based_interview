# AI-Powered Interview Analytics & Emotion Detection System

## Overview

The AI-Powered Interview Analytics & Emotion Detection System is a real-time mock interview platform that combines Computer Vision and Large Language Models (LLMs) to simulate interview interactions and analyze candidate engagement. The system evaluates facial emotions during interviews and uses Ollama-powered LLMs to generate context-aware interview questions and responses.

## Features

* Real-time facial emotion detection using webcam input.
* Emotion and engagement analysis during mock interviews.
* AI-generated interview questions and conversational responses using Ollama.
* Personalized interview feedback based on user interactions and detected emotions.
* Automated candidate assessment workflow.
* Real-time processing and response generation.

## Technologies Used

* Python
* OpenCV
* Ollama
* Machine Learning
* Computer Vision
* Prompt Engineering
* NumPy

## System Workflow

1. User starts a mock interview session.
2. Webcam captures facial expressions in real time.
3. OpenCV processes video frames and identifies emotional cues.
4. Ollama generates interview questions and responds dynamically to user inputs.
5. Emotion data and interaction patterns are analyzed throughout the session.
6. The system generates personalized feedback and engagement insights.
